# College_Event_Portal
A responsive front-end prototype built with plain HTML, CSS, and JavaScript.

## Open it
1. Extract `College _event_portal.zip`.
2. Open the folder in Visual Studio Code.
3. Open `index.html`.
4. To run it in a browser, use VS Code's Live Server extension, or simply open `index.html` in your browser.

## Demo features
- Student overview and profile
- Total APP points and previous event history
- Upcoming events filtered by Technical, Cultural, and Sports
- Event details and registration flow
- Simulated QR/payment step (no real payment)
- Registration list and demo event completion that updates APP points

## Important
This is a front-end demo. Login, database persistence, notifications, and payment gateway integration are not connected. Demo values are hard-coded in `index.html`.
